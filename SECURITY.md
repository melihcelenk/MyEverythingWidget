# Security Policy

## Supported versions

Security fixes go into the latest release published on the Microsoft Store and on the `master` branch.

## Reporting a vulnerability

Please report security problems privately, not in a public issue:

1. Open the [private reporting form](https://github.com/melihcelenk/MyEverythingWidget/security/advisories/new)
   (repository **Security** tab → **Report a vulnerability**).
2. Describe the problem, the steps to reproduce it and the version you used (Settings → About).

You will get an answer within seven days. Once a fix is released, the advisory is published with credit to the
reporter, unless you ask otherwise.

## What the app does with your data

My Everything Widget keeps your apps, notes and images on your PC. It sends nothing anywhere, except that a web
shortcut fetches its site icon from that site. See the [privacy policy](docs/general/PRIVACY_POLICY.md).
